How releases are counted. The Accessories group covers system-neutral paints, brushes, hobby tools, dice, and other accessories. Accessories made for a specific game appear under that game. Some releases apply to more than one category. When grouped by game system, a shared kit counts once in each applicable game, so the bars can add up to more than the number of distinct offerings.
